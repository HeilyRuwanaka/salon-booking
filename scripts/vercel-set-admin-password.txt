Update live admin password on Vercel (2 minutes)

1. Open https://vercel.com → project salon-booking
2. Settings → Environment Variables
3. Find ADMIN_PASSWORD → Edit
4. Set value to the same password as your local .env.local (ADMIN_PASSWORD)
5. Save for Production + Preview
6. Deployments → … on latest → Redeploy

Until you do this, the live site still uses the old password you first deployed with.
